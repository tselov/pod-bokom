## Запуск на компьютере

Для загрузки `units.json` нужен локальный HTTP-сервер. Из папки проекта:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. На Windows при необходимости используйте `py -m http.server 8000`. Также подходит расширение Live Server в VS Code. Двойной щелчок по HTML не загружает каталог из JSON из-за ограничений браузера для `file://`.

Корпуса и секции не указаны владельцем: `null`, в сообщениях и карточках не выдумываются.

Свободная №87 добавлена отдельно после повторного подтверждения владельцем. Площадь, категория и цена равны `null`: карточка показывает «Уточняется» и «Стоимость по запросу», обращение просит эти сведения. №86 из исходного списка сохраняется отдельной занятой кладовой площадью 5,25 м².

Объект содержит:

| Поле | Значение |
| --- | --- |
| `id` | Уникальный ID с адресом, корпусом и номером, например `republic-205-b2-92` |
| `addressId` | Ключ адреса в `addresses` |
| `building`, `section`, `number` | Числовые значения; корпус и секция могут быть `null`, если не предоставлены |
| `area` | Число в м² с точкой в JSON или `null`, если площадь не предоставлена |
| `category` | `compact`, `universal`, `spacious` или `null` при неизвестной площади |
| `status` | `available` / `occupied` / `on_request` (наличие не подтверждено) |
| `monthlyOfferPrice` | Месячная цена нового предложения; `null` у занятых и при неизвестном наличии |
| `updatedAt` | Дата актуализации `YYYY-MM-DD` |
| `photo` | `null` или локальный файл `photos/name.jpg` / `images/name.webp` |
| `plan` | `null` или путь к схеме своей секции |

При освобождении: смените `status` на `available`, укажите актуальную `monthlyOfferPrice`, обновите даты объекта и каталога, сохраните и опубликуйте файл. Объект автоматически попадёт в свободные. Если цена `null`, для свободного применяется тариф его категории. Цена занятого объекта на странице не показывается. Для `on_request` цена не показывается, доступно только уточнение наличия с нейтральным текстом обращения. Это публичный каталог, сведения об арендаторах сюда не добавлять.

Тарифы заданы в `categories`: 3 000 / 4 000 / от 5 000 ₽ в месяц. Умножения на площадь нет. При добавлении новых категорий или адресов дополните словари, затем массив `units`; фильтры формируются из данных. Фильтр адреса использует `addressId`; фильтры корпуса и секции учитывают выбранный адрес и выключены, если таких данных нет. Для новых адресов добавьте карту и планы в блок расположения. Для Машарова, 10 карта, маршрут Яндекса и 2ГИС используют полный адрес без выдуманных координат; планы пока не предоставлены. При выборе этого адреса общая картинка Республики и её схемы скрываются.

Фотография заменяет пиктограмму без изменения карточки. Пока используются нейтральные пиктограммы и исходное схематичное изображение кладовой; подписи «Иллюстрация» удалены по просьбе владельца. Реальными фотографиями объектов они не называются. При ошибке загрузки фото возвращается пиктограмма. Поддержаны JPG, PNG, WEBP, AVIF; относительные пути в `photos/` и `images/`.

## Карта и схемы

Сохранены Яндекс Карта, прямые ссылки на Яндекс Карты, маршрут и 2ГИС. Выбор корпуса синхронизирует адрес, карту и пояснения. Есть повтор загрузки и внешние ссылки при недоступности виджета. Событие загрузки iframe не доказывает исправность содержимого стороннего сервиса.

`plans-data.js` хранит реестр: корпус → секция → путь, ширина и высота.

- Корпус 1: десять PNG, секции 1–10.
- Корпус 2: семь PNG, секции 1, 2, 3, 4, 6, 7, 8. Схемы секции 5 в архиве нет, кнопка для неё не создаётся.

Новые файлы из архивов владельца от 04.11.2026 скопированы без перерисовки, изменения номеров, выделений и байтов. Прежние SVG заменены PNG и удалены из текущей версии; они остаются в истории Git. Имена опубликованных файлов: `floorplans/republic_205-<корпус>-<секция>.png`.

Выбор корпуса синхронизирует карту, адрес и набор секций. Выбор секции запоминается отдельно для каждого корпуса. Увеличение 100–400%, открытие оригинала и скачивание используют один и тот же файл. Карточка кладовой открывает план своего корпуса и своей секции; схемы одного дома не подставляются другому. Подсветка на исходных схемах сохранена как в файлах владельца; статус аренды указан в каталоге.

`neighborhood-plan.jpg` — исходная общая схема, сохранена целиком. Источник: https://cdn.brusnika.ru/media/complex/master_plan_image/%D0%A0205_52.jpg . Изображение не выдаётся за фотографию помещения. Изображение `buildings-highlighted.jpg` не используется на странице.

## Обращение

«Записаться на осмотр» открывает диалог с номером, адресом, корпусом, секцией, площадью и ценой. Есть копирование, телефон и ссылка `https://t.me/Skladex?text=…` с текстом, закодированным через `encodeURIComponent`. Официальный формат Telegram: https://core.telegram.org/api/links#public-username-links . Если клиент Telegram не вставил черновик, посетитель может скопировать текст вручную.

Отправляет сообщение сам посетитель. Переход в чат, копирование и показ диалога не считаются заявкой, оплатой или бронью. Занятую кладовую нельзя отправить в сценарий записи: проверяется статус и в интерфейсе, и перед формированием сообщения.

## Аналитика — подготовлена, выключена

В `site-config.js` установлены `metricaEnabled: false`, `metricaCounterId: null`. До включения нужно создать счётчик и цели, согласовать обработку данных и обновить документы. После этого вписать настоящий ID и явно включить. Без этого запросов в Метрику нет.

Подготовлены события `address_select`, `category_select`, `building_select`, `unit_view`, `inspection_click`, `availability_click`, `telegram_click`, `phone_click`. `unit_view` — просмотр не менее 35% свободной карточки через IntersectionObserver, один раз за открытие страницы. В неподдерживаемом браузере просмотр не выдумывается. События содержат только `unitId`, `addressId`, `building`, `category`, `section`; тексты обращений и персональные данные не передаются. Для отладки есть DOM-событие `skladex:analytics`. Вебвизор, автоматическое отслеживание ссылок и карта кликов выключены.

Событие успешной отправки не реализовано: своей формы и серверного подтверждения пока нет.

## Документы и следующие этапы

`documents.html` содержит подтверждённые условия и явно отмечает недостающие реквизиты/документы. Это не готовая политика обработки персональных данных и не договор. Форма обратного звонка не подключена до появления безопасного сервера и необходимых документов. Вымышленные ИНН, ОГРНИП, e-mail и адрес арендодателя не опубликованы.

1. Получить подтверждённые реквизиты, договор, правила хранения, порядок возвратов и политику обработки данных.
2. Добавить фото и при необходимости собственную форму. Сервер должен валидировать ввод, обеспечивать ограничения запросов, контролировать доступ к данным и подтверждать реальную доставку заявки. Согласия и сроки хранения определяются до запуска.
3. Подключить Метрику после подготовки документов.
4. Подключить оплату по описанию в `INTEGRATIONS.md`.
