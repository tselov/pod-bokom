# СКЛАДЭКС — пространство для вещей

Одностраничный сайт на HTML, CSS и JavaScript, без фреймворков, сборки и установки библиотек. Бренд и тексты предоставлены владельцем. Подтверждённые адреса: Тюмень, улица Республики, 205, корпус 1 и корпус 2. Адрес Николая Машарова, 10 не используется по уточнению владельца.

## Открытие и публикация

Распакуйте архив и откройте `index.html` в современном браузере. Страница работает локально; для внешней карты нужен интернет. Необязательный локальный сервер: `python3 -m http.server 8000`.

Для GitHub Pages все файлы и папка `floorplans` должны лежать в корне репозитория. Источник публикации: `main`, `/ (root)`. После отправки изменений дождитесь успешного задания `pages build and deployment` в Actions. Файлы CSS и JavaScript подключаются с версией `skladex-20261104`, чтобы браузер не использовал старое оформление.

## Структура

- Преимущества — четыре причины использовать индивидуальную кладовую.
- Площади — ориентировочные форматы 2–4, 4–5 и 5–7 м². Фильтры меняют список и счётчик. Это не каталог свободных помещений: наличие, размеры и цены подтверждаются индивидуально.
- Как арендовать — три шага: уточнить варианты, посмотреть, оформить аренду.
- Адрес — выбор корпуса, точный объект на Яндекс Картах, маршрут, резервная ссылка на 2ГИС, изображение домов с подтверждёнными метками 1/2.
- Схемы секций корпуса 1 — все десять SVG, открытие подробного просмотра, масштаб 100–400% и скачивание оригинала. Заметная ссылка находится в блоке «Площади»; она показывает корпус 1 даже после выбора корпуса 2.
- FAQ — условия хранения, осмотра, стоимости, доступа и подтверждения брони.
- Обращение — подбор площади и описание вещей, генерация и копирование сообщения для владельца.

## Обращение и данные

На сайте нет отправки заявок, бронирования, онлайн-оплаты или сохранения введённых данных. Старые поля имени и телефона и демонстрационные цены удалены. Контакты владельца не выдуманы: сообщение предлагается скопировать и отправить самостоятельно.

Сообщение содержит выбранный формат, адрес, секцию корпуса 1 (если её выбрали) и описание вещей. Смена корпуса очищает неподходящую секцию. Изменение данных скрывает старый результат. Копирование использует Clipboard API с запасным способом; при запрете буфера текст остаётся доступным для ручного копирования, без ложного сообщения об успехе. Ввод вставляется только в `textarea.value`, не в HTML.

Без JavaScript кнопка копирования отключена. У полей нет `name`, поэтому их содержимое не попадёт в URL при нативной отправке формы. Карта обращается к внешним сервисам Яндекса. Аналитика не подключена, ключи и токены в файлах отсутствуют.

## Изображения и планы

- `storage.svg` — схематичная иллюстрация кладовой с соответствующей подписью.
- `buildings-highlighted.jpg` — ранее подготовленная иллюстрация квартала, метка 1 соответствует корпусу 1, метка 2 — корпусу 2, включая дополнительную секцию. Сам файл при обновлении бренда не менялся.
- `floorplans/republic_205-1-1.svg` … `floorplans/republic_205-1-10.svg` — схемы секций, предоставленные владельцем, без изменений геометрии и номеров.
- `favicon.svg` — знак СКЛАДЭКС.
- `neighborhood-plan.jpg` — оригинальная схема квартала из открытого источника Брусники: https://cdn.brusnika.ru/media/complex/master_plan_image/%D0%A0205_52.jpg. Файл сохранён без перерисовки. В блоке «Найдите свой дом» отображается целиком, с исходными пропорциями 2880×1360 и ссылкой на полный размер. Старые области нажатия от вертикальной картинки из этого блока удалены, выбор корпуса остаётся на подписанных кнопках.

В главном блоке три иллюстрации с ручным переключением, без автоматической анимации. Изображения сохраняют пропорции, схемы используют исходный векторный формат. Для корпуса 2 планы пока не предоставлены. Наличие конкретных кладовых и их цены не заявляются.

## Карта

Яндекс использует проверенные объекты домов: корпус 1 — 65.59686, 57.12774; корпус 2 — 65.598728, 57.12798 (долгота, широта). Ссылки на адрес и маршрут доступны независимо от виджета. Повторное нажатие на текущий корпус не перезагружает карту. При долгой загрузке и ошибке показывается подсказка с альтернативами. Событие iframe `load` подтверждает загрузку документа, но не даёт проверить его содержимое из-за ограничения браузера между доменами.

## Проверка

Проверены синтаксис JS, HTML-ссылки, идентификаторы и атрибуты доступности, наличие файлов и корректность SVG. В симуляции DOM проверены фильтры, счётчик, слайды, все десять схем, подробный просмотр, масштаб, выбранные площадь/адрес/секция в сообщении, сброс старого результата, успех и отказ копирования, переключение карты и повторная загрузка. Визуальная проверка в настоящем браузере в этой среде недоступна.


## Фирменный стиль по логотипу

На сайте применяется Manrope с кириллицей, размещённый локально в `fonts/manrope-variable.ttf`, с лицензией OFL и FONTLOG. Палитра: синий `#071E3A`, оранжевый `#F85809`, светлый фон `#F4F7FA` и белые карточки. Знак со скважиной используется в шапке, подвале и favicon. На оранжевых кнопках — тёмно-синий текст. Исходное изображение логотипа сохранено в `brand-reference.jpg`.

Визуальные примеры: `brand.html`. Правила типографики, палитры и применения: `BRAND.md`. При переносе сайта обязательно сохраняйте папку `fonts` и `brand-mark.svg`.
